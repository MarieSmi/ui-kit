# ui-kit — правила для Claude

Кит компонентов и токенов для HTML-прототипов по макетам Figma. Общие правила (подключение,
именование, версии) — в README.md, здесь только то, что важно при работе с китом.

## Процесс

- Перед работой задай вопросы, потом составь план из пунктов.
- После каждого пункта остановись: покажи результат, перечисли свои допущения и жди ок.
- Пункт плана — один компонент, один набор токенов или один экран каталога.

## Источник правды

- Вид, размеры, варианты и состояния берутся из Figma. Ссылка на узел компонента указывается
  в таблице «Состав» README и в шапке его CSS.
- Состояния — из вариантов свойства `State` в component set. Если состояния нет в макете,
  не додумывай молча: спроси или явно перечисли как допущение.
- Токены — из переменных Figma «🌍 Global Variables» (mcpY3I5yWjkPfnk1IdEiqw). `tokens.css` не
  правь руками: обнови TSV в `tools/tokens/` (выгрузка через use_figma, сверка по хешу) и запусти
  `build.py`. Имя токена — имя в Figma в нижнем регистре, `/` и пробелы → `-`.

## Figma — только чтение

- Библиотеки Figma (компоненты, переменные) не редактировать: никаких правок, Code Connect,
  описаний и комментариев. Только читать.
- Связь «компонент Figma → компонент кита» хранится в ките, в `figma-map.json`: ключ компонента
  Figma, соответствие его свойств классам кита. По ссылке на макет ищи инстансы по ключу в карте.

## Код

- Без зависимостей и сборки: чистые CSS и JS, которые открываются как есть.
- В CSS компонента — только переменные из `tokens.css`. Hex и числа допустимы, только если
  токена нет в Figma; такие места помечай комментарием `/* нет токена */`.
- Каждый компонент самодостаточен и не зависит от других компонентов кита.
- Шрифты кит хранит в `fonts/`, но компоненты их не подключают: прототип подключает `fonts/fonts.css`
  сам, если ему нужны шрифты из кита.
- Исключение: размеры `demo-frame` — числами, без токенов размеров (геометрию рамки считает JS,
  `data-ui-size` её бы сломал). Цвета и тени у рамки — токенами.

## Совместимость

- Переименование класса, параметра JS или токена ломает прототипы — это мажорная версия.
  Перед таким изменением предупреди и предложи способ без поломки.
- Старые теги не трогай: прототипы подключены по ним.
