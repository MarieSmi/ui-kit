# switch

Компонент ui-kit: переключатель — включает и выключает настройку, изменение применяется сразу. Только CSS, без JS.

Перенесён из кода Saby — `Controls/toggle:Switch`. В Figma это component set `switch` библиотеки
«⚙️ Default components» (`nuC4KFMiS36uDWDUp9wKGl`, ключ `026125b305039d03eaf847e61bfd4f9c45b56bc7`).
Виды, размеры и состояния взяты из кода и живого примера Saby Components, с макетом не сверялись.

Цвета и размеры берутся из токенов кита, поэтому переключатель перекрашивается вместе с `data-ui-theme`
и меняет размер с `data-ui-size`.

## Подключение

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/MarieSmi/ui-kit@1.17.0/tokens.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/MarieSmi/ui-kit@1.17.0/components/switch/switch.css">
```

`tokens.css` подключается первым. Шрифт подписи (Inter) подключает прототип.

## Разметка

```html
<label class="switch">
  <input class="switch__input" type="checkbox" role="switch" checked>
  <span class="switch__button"></span>
  <span class="switch__caption">Поисковая индексация</span>
</label>
```

Значение хранит настоящий `input`: клик по переключателю или подписи меняет его без JS, значение читается
через `input.checked`. Без подписи `.switch__caption` не нужен, тогда у `input` задайте `aria-label`.

## Классы

**Вид** — `viewMode`:

| Класс | Saby | Как выглядит |
|---|---|---|
| без класса | `filled` | залитая дорожка: серая выключена, акцентная включена; кружок белый |
| `.switch--outlined` | `outlined` | дорожка с рамкой без заливки; кружок серый выключен, акцентный включён |

**Размер** — `size`:

| Класс | Дорожка | Кружок |
|---|---|---|
| `.switch--size-s` | 20 × 8 | 12, с рамкой, выступает за дорожку |
| без класса или `.switch--size-m` | 24 × 16 | 12 |
| `.switch--size-l` | 48 × 32 | 24 |

Размеры — из токенов `--components-toggle-switcher-*`, в таблице значения размера default.

**Подпись:**

| Класс | Saby | Что делает |
|---|---|---|
| без класса | `captionPosition="end"` | подпись справа |
| `.switch--caption-start` | `captionPosition="start"` | подпись слева |
| `.switch--multiline` | `multiline` | длинная подпись переносится, дорожка остаётся у первой строки |

Без `.switch--multiline` длинная подпись обрезается многоточием.

**Состояния:**

| Состояние | Класс | Атрибут или псевдокласс |
|---|---|---|
| включён | — | `checked` у `input` |
| наведение | `.is-hover` | `:hover` |
| только чтение | `.is-readonly` | `disabled` у `input` |

При наведении дорожка темнеет, подпись подчёркивается. Включённый переключатель — подпись основного цвета,
выключенный — цвета метки. Отдельного вида фокуса нет: при фокусе с клавиатуры — обводка браузера вокруг дорожки.

## Отличия от Saby

- Нет `resetValue` (бледный вид значения по умолчанию), `switchColor` (свой цвет включённого), `additionalCaption`,
  `captionTemplate`, `validationStatus` и вертикальной ориентации дорожки.
- Рамка дорожки и кружка — внутренняя тень, а не `border`: внешние размеры те же, что в Saby.
- `multiline` выравнивает дорожку по первой строке отступом, а не по базовой линии текста.

## Значения без токена

Помечены в CSS комментарием `/* нет токена */`:

- толщина рамки дорожки и кружка 1px;
- прозрачность дорожки в `readOnly` — 30 %;
- отступ обводки фокуса 1px.

Отступ кружка от края дорожки токена не имеет (в Saby — `--marker_border-offset_switcher`): считается как
половина разницы высот дорожки и кружка, значения совпадают с Saby.
