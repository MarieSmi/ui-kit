- Иконки разделов аккордеона — шрифт кита `Accordion-Font`. В README компонента — коды глифов для 224 имён набора
  иконок аккордеона Saby: шрифт без имён, они сопоставлены с SVG Saby по форме.
- Каталог: страницы и плитки новых компонентов в группе «Стандартные». Копии примеров в плитках получают свою
  группу радиокнопок и не снимают выбор на странице компонента.
