# Изменения

## 1.2.0 — 28.10.2026

- Новый компонент `components/checkbox` — чекбокс из component set `checkbox` библиотеки
  «⚙️ Default components» (`nuC4KFMiS36uDWDUp9wKGl`, `14613:12425`). Только CSS, внутри настоящий
  `<input type="checkbox">`. Виды `.checkbox--outlined / --filled / --ghost`, `.checkbox--reset` (resetValue,
  только с outlined), подпись слева `.checkbox--caption-start`; значение `:checked`, третье состояние
  `:indeterminate` и `.is-indeterminate`, наведение `:hover` и `.is-hover`, readOnly `:disabled` и `.is-readonly`
  (только у outlined, как в макете). Вариант с иконкой вместо подписи (`captionTemplate=icon`) не входит.
  Рамка, галочка и квадрат — векторы макета в масках, цвета — токены. Значения без токена помечены
  `/* нет токена */`. Состояния написаны через `:has()`.
- `figma-map.json`: запись о чекбоксе.
- Каталог: раздел «Чекбокс» со всеми видами, значениями и состояниями и переключателем captionPosition.
  Сборщик артефакта вшивает CSS чекбокса.

## 1.1.1 — 28.10.2026

Только каталог и пример кнопки: CSS и API компонентов не менялись.

- Меню в два уровня: «Компоненты» (Кнопка, Вспом. обл.) и «Переменные» (Цвета, Размеры, Тени). На экране
  только выбранный раздел, в «Компонентах» — один компонент; адреса `#button`, `#demo-frame`, `#colors`,
  `#sizes`, `#shadows`. Подсвечен пункт, который сейчас на экране.
- По умолчанию светлая тема (не следует за темой системы, выбор не запоминается) и кнопки m (24px),
  в примере кнопки тоже m.
- Компоненты без карточек, всё по одной левой линии с шапкой; заголовок — выбранный компонент,
  переключатель inlineHeight — в его строке справа. Убраны поясняющие абзацы.
- Рамка демо в каталоге и README называется «Вспомогательная область».

## 1.1.0 — 28.10.2026

- Новый компонент `components/button` — кнопка из секции «Базовые» страницы «✅ Кнопки» библиотеки
  «⚙️ Default components» (`nuC4KFMiS36uDWDUp9wKGl`, `322:2761`). Только CSS. Виды `filled`, `outlined`,
  `same-outlined`, `same`, `ghost`, `link`, `square`, `translucent`; стили `.btn--style-*`, размеры
  `.btn--size-m / xl / 5xl`, кнопка-иконка `.btn--icon`, подчёркивание ссылки `.btn--underline`;
  состояния `.is-hover`, `.is-active`, `.is-readonly` и псевдоклассы `:hover`, `:active`, `:disabled`.
  Значения без токена (толщина рамки, смещения теней, прозрачность слоёв, межбуквенный интервал)
  помечены `/* нет токена */`.
- `figma-map.json`: связь компонентов Figma с классами кита, первым — кнопка.
- Каталог: раздел «Кнопка» со всеми видами, стилями и состояниями; в «Размере» остались default и mobile.
  Сборщик артефакта вшивает CSS кнопки.

## 1.0.0 — 28.10.2026

- Каркас кита: README, правила для Claude.
- `tokens.css`: 521 токен из Figma «🌍 Global Variables» — цвета, размеры, тени; темы через
  `data-ui-theme`, размеры через `data-ui-size` (префикс `ui-` — чтобы не конфликтовать с `data-theme`
  хоста артефактов). Генератор и выгрузка — `tools/tokens/`.
- `demo-frame` переехал в `components/demo-frame/` и перешёл на токены. Вид в светлой теме не
  изменился, API `DemoFrame.mount` тот же.
- Каталог `catalog/index.html`: токены по группам, превью размеров и теней, живая рамка демо.
