Цвета

Из коллекции globalColor библиотеки «🌍 Global Variables». Нажмите на токен, чтобы скопировать var(--…). Значение под именем — в текущей теме.

Размеры

Из коллекции globalSize библиотеки «🌍 Global Variables». Меняются вместе с переключателем «Размер».

Тени

Из коллекции globalShadow библиотеки «🌍 Global Variables»: размытие и цвет. Смещение в Figma токеном не задано, в превью тень без смещения.
